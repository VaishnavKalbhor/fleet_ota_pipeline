# Fleet-OTA

A learning project that simulates a secure OTA update pipeline for connected vehicles.

This is not a certified automotive system. It is a portfolio project showing CI/CD, OTA rollout, security gates, telemetry, and rollback.

## Status

Under active development -- see [docs/learning-log/](docs/learning-log/) for the week-by-week build log and [docs/mistakes-log.md](docs/mistakes-log.md) for real bugs hit and fixed along the way.
